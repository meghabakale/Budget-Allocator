🔷 CORE FEATURES

1. Shared Budget Pool

- Fields:
  totalBudget
  allocatedAmount
  remainingAmount
- Real-time updates across all users

---

2. Budget Request System
   Fields:

- departmentId
- requestedAmount
- allocatedAmount
- priorityLevel (High, Medium, Low)
- justification
- status:
  pending, approved, rejected, conflicted, under_negotiation
- version (for concurrency control)

---

3. Optimistic Concurrency Control

- Each request has a version number
- On update:
  - If version mismatch → mark as CONFLICTED

---

4. Conflict Arbitration Engine (Service Layer)
   Rules:
5. Higher priority wins
6. If same priority → earlier request wins
7. Else → admin decision

Admin can override:

- Approve
- Reject
- Adjust allocation

---

5. Cascading Recalculation Engine

- Trigger on:
  
  - request create/update
  - conflict resolution
  - admin override
  - rollback

- Must:
  
  - update remaining budget
  - re-evaluate all requests

---

6. Real-Time System (Socket.io)

Client → Server:

- CREATE_REQUEST
- UPDATE_REQUEST
- NEGOTIATE
- RESOLVE_CONFLICT

Server → Client:

- REQUEST_CREATED
- REQUEST_UPDATED
- REQUEST_CONFLICTED
- BUDGET_UPDATED
- NEGOTIATION_MESSAGE
- REQUEST_STATUS_CHANGED

---

7. Negotiation System

- Chat-based UI per request

- Messages include:
  messageId
  requestId
  senderId
  message
  timestamp

- IMPORTANT:
  Chat is only for discussion
  Decisions happen via actions:
  
  - Approve
  - Reject
  - Revise

---

8. Audit Trail + Rollback

Track:

- userId
- actionType
- entityId
- previousState
- newState
- timestamp

Rollback:

- Restore previous state
- Trigger recalculation

---

9. Export System

Formats:

- CSV (json2csv)
- PDF (pdfkit)
- JSON

Routes:

- /export/budget
- /export/requests
- /export/audit
