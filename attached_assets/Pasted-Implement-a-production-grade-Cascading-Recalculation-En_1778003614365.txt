Implement a production-grade "Cascading Recalculation Engine" for a:

Real-Time Collaborative Budget Allocation System

This module must be backend-focused (Node.js + Express + MongoDB + Socket.io) and fully compatible with a Replit environment.

---

🔷 OBJECTIVE

Build a centralized service that automatically recalculates the entire budget allocation system whenever any change occurs, ensuring:

- No over-allocation
- Consistent system state
- Real-time propagation of updates
- Automatic approval/rejection of dependent requests

---

🔷 TRIGGERS (MANDATORY)

The recalculation engine must execute whenever any of the following events occur:

- New request created
- Existing request updated
- Conflict resolved
- Admin override applied
- Request deleted
- System rollback executed

---

🔷 CORE RESPONSIBILITIES

1. Fetch current system state:
   
   - BudgetPool (total, allocated, remaining)
   - All active BudgetRequests

2. Reset allocation state:
   
   - Set allocatedAmount = 0 for all requests
   - Reset statuses where needed

3. Apply allocation logic:
   
   Sort all requests based on:
   
   1. priorityLevel (High > Medium > Low)
   2. createdAt (earlier first)

4. Allocate budget sequentially:
   
   For each request:
   
   - If requestedAmount ≤ remaining budget:
     status = APPROVED
     allocatedAmount = requestedAmount
   - Else:
     status = CONFLICTED or REJECTED
     allocatedAmount = 0

5. Update budget:
   
   - allocatedAmount = sum of approved allocations
   - remainingAmount = totalBudget - allocatedAmount

---

🔷 REAL-TIME INTEGRATION

After recalculation:

Emit Socket.io events:

- BUDGET_UPDATED
- REQUEST_STATUS_CHANGED
- REQUEST_CONFLICTED

Ensure all connected clients receive updated data instantly.
